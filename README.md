# 🏦 Flask Bank App

A simple banking web application built with **Flask (Python)**.  
Users can **deposit, withdraw, and check balance** through a clean web interface.

---

## ✨ Features
- Deposit and withdraw money with validation.
- Check account balance in real-time.
- HTML templates with simple UI.
- Error handling for invalid inputs.
- Built with Flask best practices (routes, templates, forms).
